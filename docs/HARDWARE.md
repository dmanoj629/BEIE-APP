# Target Hardware Environment

- OS: Windows 11 / Linux compatible
- Python Version: 3.12+ (tested on Python 3.12.10)
- Execution Profile: Local CPU execution. No dedicated GPU required.
- Memory: Designed to operate cleanly under 4 GB RAM via memory-mapped Parquet and DuckDB streaming.
- Model Weights: Zero large binary model downloads required. Deterministic analytics first.
